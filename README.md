# Wina Juice (ዊና ጁስ) Digital Menu Website

A modern, responsive digital menu website for **Wina Juice**, built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. 

**100% faithful to the official physical menu photograph.** Every item, price (in Ethiopian Birr - ETB), description, ingredient, and branch contact phone number has been transcribed and verified directly from the photographed menu.

---

## 🌟 Key Features

- **100% Authentic Menu Data**: Exactly 106 items mapped across 10 categories from both sides of the physical menu.
- **Dual Language Support**: Seamless presentation in both English and Amharic (አማርኛ) using typography tailored for Ethiopic script (Noto Sans Ethiopic) and modern Latin sans-serif.
- **Physical Menu Visual Identity**:
  - Wina signature emerald green (`#16a34a`) and crimson red (`#b91c1c`) color system.
  - Authentic card outlines with dot leaders connecting item names and prices.
  - Wina Juice brand logo based on the original leaf & apple design.
- **Dietary & Fasting (የፆም) Filters**:
  - Dedicated tags for Ethiopian Fasting / Vegan (የፆም), Fish / Tuna (አሳ / ቱና), Chicken (ዶሮ), Beef (ስጋ), and Juices / Mojitos.
- **Instant Search**: Search through English names, Amharic names, ingredients, or descriptions with real-time feedback.
- **Original Menu Inspector**: High-resolution lightbox modal allowing customers and managers to inspect the original physical menu photographs (Side 1 and Side 2) with zoom and side switching.
- **Extra Toppings & Takeaway Packaging**: Complete transcription of the "ተጨማሪ Extra" (Mozzarella, Enjera, Bread, Tuna, etc.) and "Take Away / ማሸጊያ" (Burger bag, Pizza box, Juice cup, Foil bag) pricing boxes.
- **6 Addis Ababa Branch Directory**:
  - Summit (ስሚት): `0961-33 35 55`
  - Bole (ቦሌ): `0975-33 25 33`
  - Piazza (ፒያሳ): `0905-50 50 42`
  - Shola (ሾላ): `0987-27 27 27`
  - Adisu Gebeya (አዲሱ ገበያ): `0945-29 29 29`
  - Ras Desta (ራስ ደስታ): `0931-00 33 00`
  - Direct one-click phone dial links on mobile and desktop.
- **Fully Responsive**: Optimized for smartphones, tablets, laptops, and large desktop screens without horizontal scroll.

---

## 🛠️ Development & Deployment

### Local Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
Generates optimized assets inside the `dist/` directory ready for deployment.

### Deploy to Vercel
You can deploy directly to Vercel via CLI or GitHub integration:
```bash
npx vercel
```
Or import the repository directly on [Vercel Dashboard](https://vercel.com). The provided `vercel.json` configures single-page application routing automatically.
